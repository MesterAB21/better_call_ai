Physics & Motion Specs

Phase 1: Initial Tilt 0.0s – 1.25s

Main beam pivots CCW (-9°). Left pan rises seamlessly while right pan descends.

Phase 2: Reversal Shift 1.25s – 3.75s

Beam rotates smoothly clockwise to +9°. Left pan descends as right pan ascends.

Phase 3: Return to Equilibrium 3.75s – 5.0s

Beam decelerates back to horizontal (0°). Perfectly balanced loop conclusion.

True Gravity Counter-Rotation: As the crossbeam rotates, the pans are dynamically counter-rotated in real time so their hanging chains remain strictly vertical.

// GSAP Timeline initialization for Balance Scale

  // Phase 1: Left Pan UP, Right Pan DOWN (0.0s -> 1.25s)
  .to("#main-beam-group", {
    rotation: -9,
    transformOrigin: "250px 115px",
    duration: 1.25,
    ease: "power1.inOut"
  }, 0)
  .to("#left-pan-assembly", {
    rotation: 9,
    transformOrigin: "70px 115px",
    duration: 1.25,
    ease: "power1.inOut"
  }, 0)
  .to("#right-pan-assembly", {
    rotation: 9,
    transformOrigin: "430px 115px",
    duration: 1.25,
    ease: "power1.inOut"
  }, 0)

  // Phase 2: Reverse Shift - Left DOWN, Right UP (1.25s -> 3.75s)
  .to("#main-beam-group", {
    rotation: 9,
    transformOrigin: "250px 115px",
    duration: 2.5,
    ease: "power1.inOut"
  }, 1.25)
  .to("#left-pan-assembly", {
    rotation: -9,
    transformOrigin: "70px 115px",
    duration: 2.5,
    ease: "power1.inOut"
  }, 1.25)
  .to("#right-pan-assembly", {
    rotation: -9,
    transformOrigin: "430px 115px",
    duration: 2.5,
    ease: "power1.inOut"
  }, 1.25)

  // Phase 3: Return to Horizontal Equilibrium (3.75s -> 5.0s)
  .to("#main-beam-group", {
    rotation: 0,
    transformOrigin: "250px 115px",
    duration: 1.25,
    ease: "power1.inOut"
  }, 3.75)
  .to("#left-pan-assembly", {
    rotation: 0,
    transformOrigin: "70px 115px",
    duration: 1.25,
    ease: "power1.inOut"
  }, 3.75)
  .to("#right-pan-assembly", {
